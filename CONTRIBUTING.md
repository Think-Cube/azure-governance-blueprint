# Contributing to Azure Platform Governance Blueprint

Thank you for your interest in improving this governance blueprint!

## How to Contribute

### Reporting Issues

Use GitHub Issues to:
- Report outdated or incorrect guidance
- Suggest missing governance areas
- Identify broken references or links

### Proposing Changes

1. Fork this repository
2. Create a feature branch: `git checkout -b improve/section-name`
3. Make your changes
4. Submit a Pull Request using the provided template

### Guidelines

- Keep guidance vendor-neutral where possible; note Azure-specific nuances clearly
- Align recommendations with the latest [Microsoft Cloud Adoption Framework](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework) and [Azure Well-Architected Framework](https://learn.microsoft.com/en-us/azure/architecture/framework)
- Replace `[REPLACE THIS PLACEHOLDER WITH YOUR POLICY]` blocks with concrete, reusable guidance — not organization-specific values
- Keep the document structure consistent: section heading → guidance bullet points → policy placeholder

### Style

- Use **bold** for important terms on first use
- Use `>` blockquotes for external references
- Use numbered lists for ordered steps, bullet lists for unordered guidance
- Link to official Microsoft Learn documentation wherever possible
